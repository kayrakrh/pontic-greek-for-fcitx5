# Pontic Greek for Fcitx5

**Ποντιακά · Pontus Rumcası**

Ένας τρόπος εισαγωγής κειμένου για την ποντιακή ελληνική διάλεκτο, βασισμένος στο Fcitx5 και το m17n.

Fcitx5 ve m17n tabanlı, Pontus Rumcası ile yazmayı kolaylaştırmayı amaçlayan bir giriş yöntemi.
